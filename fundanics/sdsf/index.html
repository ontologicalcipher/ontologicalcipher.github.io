Stellar Distance Scaling Formula

The distance ratio is dimensionless when both reference distances use the same unit. Therefore, R has the same distance unit as Dstar.

04 / Scientific assessment

What is established?

Arithmetic
  • The given distances produce a ratio of about 389.17.
  • Multiplying by a dimensionless factor preserves the distance unit.
  • The calculator reproduces the proposed operation.
Still unproven
  • The formula does not independently determine stellar distance.
  • The arithmetic alone establishes no new physical law.
  • Physical significance requires an independent prediction and observational tests.
!

Scientific note
To test SDSF as a physical model, define an independently measurable quantity, make predictions that differ from existing methods, and test those predictions against observations.
