01 / Proposed equation

The formula

R = Dstar × DSun–EarthDMoon–Earth
The ratio uses reference distances expressed in the same unit, so the ratio itself is dimensionless. The result R therefore has the same distance unit as Dstar.

04 / Scientific assessment

What this does — and doesn't — show

Arithmetic established
  • The stated reference distances produce a ratio of approximately 389.17.
  • Multiplying a distance by a dimensionless ratio preserves its unit.
  • The calculator reproduces the proposed operation for the input supplied.
Not yet established
  • The formula does not independently determine a star's distance.
  • The arithmetic alone does not establish a new physical law or constant.
  • Physical significance requires an independently measurable prediction and testing against observations.
!
Scientific note

For SDSF to become a useful scientific model, it needs a clearly defined observable, predictions that differ from existing methods, and tests using measurements not used to construct the formula.
